pixels/ — the Pixel tab of the sticker tray.

manifest.json lists the pictures by group; each entry is { src, w, h, anim?, credit?, link? }.
Add a picture by dropping it in a group folder and adding a line to the manifest,
or regenerate the whole folder from the fan-site collection with the generator script.
Animated GIFs and WebPs keep their animation on the canvas (up to 16 frames).

These are fan-collected 2000s Cinnamoroll pixel graphics (sources in CREDITS.txt);
